## Чему научатся

- Понимать, из чего состоит цифровая картинка: пиксель, разрешение, RGB, соотношение сторон, форматы файлов.
- Запускать готовый скрипт на Python и менять в нём параметры.
- Понимать, что такое библиотека и как её подключить (`pip install`, `import`).

## Подготовка (за день до занятия)

**На каждом компьютере должно быть:**

1. Python 3.9 или новее.
2. Установленные пакеты: `pip install pillow PyQt6 pixelkid`. Нужна `pixelkid` **версии 0.2.0 или новее** — в ней PDF-раскраска. Если на компьютере уже стоит старая версия: `pip install -U pixelkid`.
3. Редактор кода (VS Code или IDLE).
4. По желанию — цветной принтер, чтобы в конце раздать распечатанные раскраски.
5. Папка с 3–4 учебными фото (портрет, животное, пейзаж) на случай, если ребёнок не принёс своё. Свои фото детей — только с их согласия, лучше не лица одноклассников.

**Проверка за 1 минуту.** Запустите на каждом компьютере:

```
python -c "import PIL, tkinter, PyQt6; print('ok')"
```

**Типичные проблемы и решения:**

| Что видим | Причина | Что делать |
|---|---|---|
| `No module named 'PIL'` | Не установлен Pillow | `pip install pillow` |
| `No module named '_tkinter'` (Mac) | В Python от Homebrew нет окон tkinter | `brew install python-tk@3.14` (под вашу версию Python) |
| `externally-managed-environment` | Системный Python запрещает `pip` | Создать окружение: `python3 -m venv .venv`, затем `source .venv/bin/activate` |
| `pip` или `python` «не найдено» (Windows) | При установке Python не поставили галочку Add to PATH | Переустановить Python с галочкой или писать `py -m pip ...` |
| `No matching distribution found for pixelkid` | Нет интернета или очень старый pip | Обновить pip: `python -m pip install -U pip`. Без интернета: `pip install pixelkid-0.2.0-py3-none-any.whl` (собирается командой `python -m build` в папке `pixelkid`) |

> **Важно.** Библиотека опубликована: https://pypi.org/project/pixelkid/ (версия 0.2.0 с PDF-раскраской). Перед занятием проверьте `pip install pixelkid` на компьютерах класса. Если там нет интернета — используйте файл из таблицы выше.

**Для себя:** заранее подготовьте 2–3 пиксельных ролика (ссылки или QR-код) для слайда 9. Тренды меняются, поэтому свежие примеры лучше выбрать самому за пару дней до занятия.

### Блок «Из чего состоят картинки» (20 минут)

Идея: не читать слайды, а **спрашивать**, затем показывать ответ. Каждый слайд — 2–3 минуты.

| Слайд | Вопрос детям | Ответ / вывод |
|---|---|---|
| 3. Картинка — это числа | «Как компьютер видит котика?» | Не видит. Для него это таблица чисел, в каждой клеточке цвет |
| 4. Пиксель | «Что будет, если сильно приблизить фото?» | Появятся квадратики — это и есть пиксели |
| 5. Разрешение | «Какая картинка чётче и почему?» | Та, где больше пикселей. Full HD = 1920×1080 ≈ 2 млн пикселей. Пиксель-арт — это специально маленькое разрешение |
| 6. RGB | «Как получить оранжевый?» | Красный 255 + зелёный ~106 + синий 0. Спросите: «Какой цвет (0, 0, 0)? А (255, 255, 255)?» (чёрный и белый) |
| 7. Соотношение сторон | «Какое соотношение у TikTok? А у YouTube?» | 9:16 и 16:9. Если растянуть фото — оно искажается |
| 8. Форматы | «Чем PNG отличается от JPG?» | JPG — фото, сжатие с потерями; PNG — без потерь и с прозрачностью (в нём храним пиксель-арт). SVG — не из пикселей, а из формул |

**Мини-активность (по желанию, 3 минуты, без компьютеров).** Каждый рисует на клетчатой бумаге смайлик 8×8 клеток — так наглядно видно, что картинка = сетка клеток.

### Практика 1: свой пиксель-арт (20 минут)

1. Дети создают файл `main.py` и копируют код со слайда 11: здесь алгоритм написан «руками», чтобы было видно, как он устроен. Потом можно открыть готовый `main.py` из папки проекта: он делает то же самое одним вызовом `pixelate` из библиотеки.
2. Кладут рядом файл `photo.jpg`, запускают, получают `pixel_art.png`.
   Готовый `main.py` вдобавок сохраняет `my_coloring.pdf` — цветную раскраску по номерам с логотипом МАСТЕРСАМ (страница 1 — для печати, страница 2 — ответ).
3. **Новичкам:** поменять числа `12` и `32`, посмотреть, как меняется результат. Заполнить таблицу «значение → что получилось».
4. **Опытным:** вынести параметры в переменные, спросить их через `input()`, сделать цикл `for` с несколькими размерами, сохранить 5 картинок.
5. **Самым быстрым:** сделать из фото аватарку 1:1 или обрезать фото до 9:16.

### Практика 2: приложение «Пиксель-раскраска» (10 минут)

Приложение показывает, как из одной функции получается настоящая программа с окнами. Детям не нужно разбирать его код (это PyQt6, он сложнее урока).

1. `python app/pixel_paint.py`
2. «Открыть фото» → выбрать размер сетки (10–48) и число цветов (2–16).
3. Выбрать цвет в палитре и закрашивать клетки по номерам (можно вести мышью с зажатой кнопкой).
4. Зажать «Показать подсказку» — видно, какой должна быть картинка. «Закрасить всё» — автозаполнение. «Сохранить» — PNG. «PDF-раскраска» — PDF для печати с теми же номерами и палитрой, что на экране.

Опытным можно предложить заглянуть в `app/pixel_paint.py` и найти строку, где вызывается `pixelate`.

## Работа со смешанной группой

| Уровень | Задача |
|---|---|
| **Без опыта** | Запустить готовый код, менять числа, фиксировать результат. Достаточно понять, что `12` отвечает за размер пикселя, а `32` — за число цветов |
| **Есть опыт** | Переменные и `input()`, цикл `for`, функция, обработка ошибок (`try/except` на неверный ввод) |
| **Продвинутые** | Свой фильтр: перевести в чёрно-белый, добавить рамку, сделать «градиентную» палитру; прочитать код `pixelkid` и объяснить его. Сравнить свой код со слайда 11 с библиотекой: почему у библиотеки цвета сочнее? (Подсказка: она подбирает палитру методом k-means в пространстве Lab и ставит в клетку самый частый цвет, а не средний — см. `pixelkid/README.md`) |

Совет: сажайте новичков рядом с опытными, но опытным даём **собственное** задание, а не роль помощника на всё занятие.

## Критерии успеха

- Каждый ребёнок получил файл с пиксель-артом из своего фото.
- Ребёнок может объяснить, что делают числа `pixel_size` и `colors`.
- Ребёнок может назвать, что такое пиксель, и зачем нужны три числа RGB.
